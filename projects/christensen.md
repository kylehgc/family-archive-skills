# Christensen ancestry

**Site:** [christensen-ancestry.pages.dev](https://christensen-ancestry.pages.dev)

A Danish family line, traced from a family that emigrated to Canada in the 1950s back through Funen's parish registers, censuses and estate records, over about ten generations. It was built between July and September 2026, mostly by a coordinating session running parallel research agents, one per branch of the tree.

## What's in it

- **Every claim cites a saved scan.** Each one carries a register, book and page reference, a transcription and a translation.
- **Fast routes into the Danish archives with no browser.** The Rigsarkivet's Arkivalieronline image API, Daisy for estate and court series, and the DDD census database are all used directly. The method file records how each works and where each misleads: register structure, page sizes read by HTTP HEAD, characters the search engines drop.
- **Searches that found nothing are recorded as results**, each giving what was read, over what range, and the gaps.
- **An evidence audit**, in which every source was re-read against its scan with a verdict.
- **A family site** with a contact form. A relative writing back turned out to be the biggest advance in the project.

## What it taught

- **Citations.** An agent once wrote a full citation for a record it had never opened. That led to the project's first rule: cite only what you have looked at, and save the file at the moment you read it.
- **Briefs.** The coordinator's briefs were wrong several times in a single day. The agents that checked the coordinates they were handed caught the errors.
- **Saving work.** Agents that saved only at the end lost their work when they stopped.
- **Outreach.** Emails went out under the owner's name without his asking, and one of them claimed a relative would give an interview. Since then, outreach in this project is draft-only.
